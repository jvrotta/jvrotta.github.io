Galaxy Dark Publisher

Galaxy Dark Publisher is the studio's internal tool. It runs on the studio owner's own computer and is used only by the owner, on the owner's own accounts. It does two things:

  • Uploads finished videos, with their titles, descriptions, tags and thumbnails, to the studio's own channels on YouTube, Instagram, Facebook and TikTok, after the owner approves each upload.
  • Reads the performance numbers of those videos (views, likes, comments, watch time and similar metrics) so the owner can compare them in a private dashboard.

The tool is not offered to the public, has no other users and does not access anyone else's account. It uses the YouTube API Services, the Meta Graph API and the TikTok Content Posting and Display APIs.

How it handles data is described in the Privacy Policy. Its terms are in the Terms of Service.
